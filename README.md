# Отбор клиентов для маркетинговой кампании 

## Задача
Для банка нужно отобрать клиентов для рассылки предложения кредитной карты.  
Условия отбора:
- возраст 25–55 лет
- баланс на текущем счёте > 50 000 ₽
- активные клиенты (не заблокированы)

## Инструменты
- SQL (SQLite / PostgreSQL)
- DDL, DML, JOIN, оконные функции (ROW_NUMBER), CTE

## Файлы в репозитории
- `schema.sql` - создание таблиц (клиенты, счета, транзакции)
- `insert.sql` - заполнение тестовыми данными (30 клиентов, счета, транзакции)
- `queries.sql` - аналитические запросы:
  1. Отбор целевой аудитории (JOIN, WHERE, GROUP BY)
  2. Ранжирование клиентов по балансу (ROW_NUMBER)
  3. Суммарный баланс по клиентам с CTE

## Как воспроизвести
1. Открыть любой SQL-клиент (SQLiteOnline, DB Browser, PostgreSQL).
2. Выполнить `schema.sql` → создадутся таблицы.
3. Выполнить `insert.sql` → загрузятся данные.
4. Выполнить `queries.sql` → увидите результат.
